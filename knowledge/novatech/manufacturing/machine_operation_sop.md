# Machine Operation SOP

Department: Manufacturing Operations
Category: sop
Classification: internal
Version: 2026.1
Effective date: 2026-02-01
Owner: Manufacturing Operations Head

## 1. Scope

Applies to all CNC machining centres, press lines and assembly cells in Plant 1 and Plant 2, including asset classes M-100 through M-400.

## 2. Operator eligibility

Only operators certified for the asset class under the Onboarding Policy may run equipment unsupervised. Certification is verified on badge scan at the machine terminal.

## 3. Start-of-shift checks

1. Confirm the machine is clear of personnel and tooling.
2. Verify guards, light curtains and emergency stops function.
3. Check lubricant and coolant levels against the marked range.
4. Confirm the loaded program number matches the production order.
5. Run one first-article part and submit it for dimensional check.

## 4. During operation

- Never bypass an interlock or defeat a guard.
- Keep the operating envelope clear; use the tool hook for chip removal.
- Record hourly counts and any stoppage reason code in the shift log.
- Stop the machine and call the supervisor for any unusual noise, vibration, smell or alarm you do not recognise.

## 5. Alarm handling

| Alarm class | Meaning | Operator action |
| --- | --- | --- |
| A (safety) | Guard, e-stop, light curtain | Stop, do not reset, call supervisor |
| B (process) | Tool wear, coolant, feed fault | Stop cycle, follow on-screen guidance, log it |
| C (information) | Counters, shift messages | Acknowledge and continue |

## 6. End-of-shift

Clean the work area, return tooling to the shadow board, close the shift log and hand over open issues verbally to the incoming operator.
